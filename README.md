# Nanquim for Mac

Installers for Nanquim, a Mac app where everyone works from the same docs and spreadsheets, kept in your company's GitHub, with your own AI.

Nanquim is in an invitation-only beta. Request an invite at [nanquimapp.com](https://nanquimapp.com). The app asks you to sign in, and a new account opens only with an invite.

Each release has two installers:

- Apple silicon (M1 and later): `Nanquim-<version>-arm64.dmg`
- Intel: `Nanquim-<version>.dmg`
